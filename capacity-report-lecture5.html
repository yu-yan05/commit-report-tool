未来キャパ予報

Googleカレンダーから未来の稼働量を自動集計するレポートツール

課題背景　予定を詰め込みすぎて疲れる前に、未来の忙しさを見える化したかった。

仕組み（4つのパーツ）

Trigger

トリガー

GitHub Actionsで毎日自動実行

Source

ソース元

Googleカレンダーの予定データ

Process

処理する場所

GitHub Actions上でNode.jsを実行

Deliver

届ける先

GitHub PagesでURL公開

報告ツールの画面

工夫したポイント

4つのパーツ（再掲）

  • トリガー：GitHub Actionsで毎日自動実行
  • ソース元：Googleカレンダーの予定データ
  • 処理する場所：GitHub Actions上でNode.jsを実行
  • 届ける先：GitHub PagesでURL公開

デザインの工夫

  • 13週間分の未来の稼働時間を一覧で見られる
  • 20h、40hなどの基準線でキャパを直感的に判断できる
  • 緑・黄・赤で余力や危険度を見分けられる
  • 忙しさだけでなく、休息や自己投資不足も意識できる設計にした

つまずいたことと解決方法

ぶつかった課題

  • Googleカレンダーの予定が最初は0件になった
  • GitHub Actionsの権限エラーが出た
  • GitHub Pagesで公開するためにリポジトリ設定を変更する必要があった
  • GitHub Secretsに正しいカレンダーIDを入れる必要があった

解決方法

  • GitHub Actionsの権限を修正した
  • Google Calendar APIとサービスアカウントの共有設定を確認した
  • GOOGLE_CALENDAR_IDをGitHub Secretsに設定した
  • ActionsログのGet calendarを確認して、取得件数が52件になるところまで検証した
